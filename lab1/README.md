# 中国海洋大学《移动软件开发》课程实验一：第一个微信小程序

本仓库为中国海洋大学《移动软件开发》课程的实验一代码实现。项目基于微信小程序原生框架开发，旨在熟悉小程序项目的建立流程、四件套文件（WXML, WXSS, JS, JSON）的分工协作、数据绑定机制以及基础事件响应。

---

## 📌 实验目标

1. **环境与搭建**：熟悉微信开发者工具的使用，掌握不使用预设模板手动搭建小程序目录结构的方法。
2. **数据绑定与事件**：理解 WXML 与 JS 之间的数据绑定机制（MVVM 模式），学习使用 `this.setData()` 更新视图。
3. **样式与布局拓展**：练习弹性盒布局（Flexbox）、自定义导航栏适配以及基础 CSS3 动画的应用。

---

## 🛠️ 实现功能与技术细节

项目在实现基础“文本切换与计数器”功能的基础上，对界面外观与布局细节进行了适当的样式定制。

### 1. 基础逻辑实现
* **文本动态切换**：在 `index.js` 中维护问候语数组 `greetings`，通过点击事件触发 `changeText` 函数，更新当前显示的文本内容。
* **点击计数与重置**：记录按钮点击次数，并提供“重置状态”功能，重置时通过 `wx.showToast` 弹出轻量级原生提示。

### 2. 界面与交互调整
* **自定义导航栏**：全局配置 `"navigationStyle": "custom"` 取消原生导航栏。在页面加载（`onLoad`）时调用 `wx.getMenuButtonBoundingClientRect()` 获取系统胶囊尺寸，动态计算顶部内边距（`headerPaddingTop`），防止标题与系统胶囊重叠。
* **样式与视觉**：使用半透明背景与 `backdrop-filter: blur()` 实现卡片毛玻璃效果；通过 CSS 滤镜及双层边框提升头像与高亮背景间的对比度。
* **进场动画与控制**：使用 CSS3 `@keyframes` 配合 `cubic-bezier` 贝塞尔曲线编写组件上浮动画。为避免页面初始化白屏期间动画提前播放导致的闪烁现象，将动画激活状态（`loaded`）延后至 `onReady` 生命周期函数中触发，并设置 `animation-fill-mode: both`。
* **页面滚动控制**：在 `index.json` 中配置 `"disableScroll": true`，防止单页界面在部分设备上出现无意义的纵向拖拽回弹。

    └── sitemap.json           # 微信搜索引擎索引配置文件

## 💻 本地运行指南

1. **克隆本仓库到本地**：
   ```bash
   git clone https://github.com/你的用户名/你的仓库名.git
   ```
2. **导入开发者工具**：
   * 打开 **微信开发者工具**，点击 **导入项目**。
   * 选择克隆到本地的项目根目录。
   * 填入个人小程序的 `AppID`（或选择测试号）。
3. **编译预览**：
   * 点击工具栏的 **重新编译** 按钮即可在模拟器中运行并预览效果。

## ⚠️ 已知局限与后续改进

* **设备适配**：目前动态边距计算覆盖了常见的 IOS / Android 胶囊布局，但在某些特殊屏幕比例的设备上，卡片垂直间距仍需进一步微调。
* **全局状态管理**：当前状态更新完全依赖单个页面的 `data`，后续随页面增多需引入更规范的状态管理或组件化拆分。
